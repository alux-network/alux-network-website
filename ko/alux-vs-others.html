Web 2와 Web 3를 통합하는 분산 런타임

블록체인은 본질적으로 상태 전환 기계입니다. ALUX는 짧고 고립된 VM 호출을 재실행 가능한 장기 트랜잭션(Long Transaction)으로 확장합니다. 현재는 블록 간 실행과 검증 가능한 Web 2 I/O를 지원하며, 런타임 간·샤드 간 조합은 더 큰 아키텍처에 포함됩니다.

우리가 해결하는 문제

많은 블록체인 VM은 짧고 순서가 정해진 상태 업데이트에 초점을 맞춥니다. ALUX는 대기하고, 재개하고, 조율하거나 블록 경계를 넘어야 하는 워크플로까지 이 모델을 확장합니다.

  • 블록체인은 본질적으로 상태 전환 기계입니다.
  • 현재 많은 블록체인 VM은 짧고 순서가 정해진 상태 전환이라는 더 좁은 범위에 초점을 맞춥니다.

장기 트랜잭션을 위한 분산 런타임, ALUX

ALUX는 일회성 상태 업데이트를 넘어 병렬·동시·복합 상태 전환 패턴을 모델링합니다.

ALUX는 모든 트랜잭션을 짧고 고립된 상태 업데이트로 다루지 않습니다. 실행을 병렬·동시·복합 전환을 조율할 수 있는 런타임으로 모델링합니다.

실행 모델

병렬

병렬 실행

현재는 격리된 EVM 인스턴스를 병렬로 실행할 수 있습니다. WASM은 향후 이기종 VM 지원 방향에 포함됩니다.

동시성

동시성 실행

ALUX에서는 TX가 코루틴처럼 실행되어 일시 중단되고, 다시 깨어나며, 서로 교차 실행될 수 있습니다. 실행 순서는 비결정적일 수 있지만 리플레이는 결정적으로 이루어집니다.

복합

복합 상태 전환

TX는 여러 블록 높이에 걸쳐 실행되며, ALUX 트랜잭션 경계 안에서 격리와 원자적 정산을 유지한 채 온체인 작업을 재실행 가능한 HTTPS 효과와 조율할 수 있습니다. 샤드 간 조합은 아키텍처와 로드맵에 포함되어 있습니다.

복합 상태 전환과 호환성

TX는 여러 블록 높이에 걸쳐 실행되며, ALUX 트랜잭션 경계 안에서 격리와 원자적 정산을 유지한 채 온체인 작업을 재실행 가능한 HTTPS 효과와 조율할 수 있습니다. 샤드 간 조합은 아키텍처와 로드맵에 포함되어 있습니다.

ALUX는 현재 샌드박스와 Ethereum JSON-RPC를 통해 EVM 실행 경로를 제공합니다. WASM과 더 폭넓은 이기종 VM 조합은 계획 단계이며, 현재 기준 버전에는 포함되지 않습니다.

요약하면 ALUX는 모든 워크플로를 짧은 트랜잭션에 억지로 맞추지 않습니다. 현재는 블록 경계를 넘고 Web 2와 연결되는 장기 트랜잭션을 재실행할 수 있으며, 샤드 간 조합과 더 폭넓은 런타임 간 조합은 아키텍처와 로드맵에 포함되어 있습니다.
